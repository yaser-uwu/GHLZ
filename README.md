## 📖 Descripción

Mapa conceptual digital, construido de forma colaborativa en **Miro**, que organiza el ecosistema de los **sistemas distribuidos** y las relaciones explícitas entre sus conceptos.

Cada concepto incluye una definición breve (máximo 20 palabras) y al menos dos referencias bibliográficas verificadas.

Este mapa servirá como base para identificar el sistema distribuido real que se analizará en la **EXP-1 (Semana 4)**.

## 🧠 Contenido del mapa

El mapa abarca los siguientes ejes:

- 🧩 **Tipos de sistemas distribuidos**
- 📡 **Modelos de comunicación**
- 🔌 **Middleware**
- 👁️ **Conceptos de transparencia**
- 🛡️ **Tolerancia a fallos**
- ⚖️ **Teorema CAP** (consistencia, disponibilidad y tolerancia a particiones)

Todos ellos conectados mediante relaciones explícitas entre conceptos.
